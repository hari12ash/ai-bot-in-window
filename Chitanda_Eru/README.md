# 🌸 Chitanda Eru - Autonomous AI 3D Movable Character

This folder contains all files dedicated to **Chitanda Eru** (*Hyouka*).

### 🚀 Files in this folder:
- **`open_viewer.bat`**: Double-click to launch the Autonomous AI 3D movable character!
- **`index.html`**: The complete 3D interactive viewer & AI simulation.
- **`chitanda_eru.obj` & `chitanda_eru.mtl`**: Standalone 3D mesh model with materials (876 vertices, 1,560 polygons).
- **`generate_chitanda.py`**: Python script used to construct the 3D model geometry.

### 🎮 Controls:
- **AI Autopilot**: Active by default! Chitanda skips, explores landmarks, and triggers *"Watashi, Kininarimasu!"* autonomously.
- **`Tab`**: Toggle between AI Autopilot and Manual Player Control.
- **`W`, `A`, `S`, `D`**: Move manually.
- **`Shift`**: Fast schoolgirl run.
- **`Space`**: Jump.
- **`Left Click` / `E`**: *"Watashi, Kininarimasu!" ("I'm curious!")* pose with flower/star aura.
- **`C`**: Polite bow & greeting.
- **`💾 Export .GLB`**: Download `.glb` file directly from the viewer.
